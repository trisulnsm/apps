# IPDR Tagger

Tags IPDR flows with a user ID taken from IPDR Customer Database

## Application

Customer has defined IP Ranges in IPDR Customer Mappings 
Now they want ability to query by customer rather than by each IP separately. 


See [Trisul IPDR Customers Docs](https://docs.trisul.org/docs/ipdr/ipdrcustomers/)
